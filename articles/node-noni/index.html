「ので・のに・し・ために」の教え方｜「因為」も「可是」も一つじゃない

2026年10月4日

中文版（學生用）→

この記事で分かること

中国語では「因為」「可是」「為了」で済むところを、日本語は四つの形で言い分けます。学習者が混乱するのは、形が似ている（ので／のに）うえに、どれも「理由・逆接」と一言でまとめて教わるからです。

そこでこの記事では、四つを話し手の気持ちで分けて教えます。

形 気持ち 中国語のイメージ
〜ので 理由をていねいに、やわらかく言う 因為（客觀・禮貌）
〜のに 「そうなるはずなのに！」という不満・意外 明明…卻…
〜し 理由を一つ「ほかにもある」感じで並べる 又…又…、而且
〜ために 目的（為了）か、かたい原因（由於） 為了／由於

もう一つの柱は接続のルールです。名詞・な形容詞のあとは「な」が要る（学生なので、静かなのに）けれど、「し」は「だ」（学生だし）、「ために」は「の」（病気のために）。ここを表で一度に見せると、作文のミスがぐっと減ります。

学習者がよくする間違い

間違い 正しい形 ポイント
×明日は休みので、遊びに行きます。 明日は休みなので、遊びに行きます。 名詞のあとは「なので」
×日本語は難しいのに、おもしろいです。 日本語は難しいけど、おもしろいです。 不満・意外がないなら「けど」
×雨なのに、行きましょう。 雨だけど、行きましょう。 「のに」の後ろに、誘い・お願い・意志は来ない
×この部屋は静かし、駅にも近いです。 この部屋は静かだし、駅にも近いです。 な形容詞・名詞は「だし」
×この店は安いだし、おいしいです。 この店は安いし、おいしいです。 い形容詞に「だ」はつけない
×日本語が上手になるために、毎日ドラマを見ます。 日本語が上手になるように、毎日ドラマを見ます。 「上手になる」は自分で決められない →「ように」
×病気ために、学校を休みました。 病気のために、学校を休みました。 名詞のあとは「のために」
△おなかがすいたために、パンを食べました。 おなかがすいたので、パンを食べました。 原因の「ために」はかたい。日常会話では「ので」

なぜ間違えるのか

① 中国語は一つの言葉で済む

「因為」は、「から」も「ので」も「ために（原因）」も全部カバーします。「可是」も同じで、「けど」と「のに」の区別がありません。だから学習者は、「のに＝けどのかたい版」だと思って、作文でどんどん使ってしまいます。「のに」には「明明…卻…」の不満が入っている、という感覚がないのです。

② 「ので」と「のに」は一文字違い

形がそっくりなので、な形容詞・名詞の接続（〜なので／〜なのに）もセットで覚えられます。その一方で、意味も似ていると勘違いしやすく、聞き取りでもよく聞き間違えます。

③ 接続が形ごとにバラバラ

名詞のあとは、ので・のには「な」、しは「だ」、ためには「の」。しかも、い形容詞には何もつきません。一つずつ別の日に習うと、頭の中で混ざります。

④ 「為了」＝「ために」だと思っている

中国語の「為了」は、「為了變得更好」のように、自分では決められないことにも使えます。でも日本語の「ために」は、「買う」「行く」のように自分で決められる動詞だけ。「上手になる」「聞こえる」のような動詞には「ように」を使います。このルールは中国語にないので、一番直りにくい間違いです。

教室での教え方

① 接続は一枚の表にまとめる

四つを別々の日に習っていても、復習のときは必ず一枚に並べます。

い形容詞（安い） な形容詞（静か） 名詞（雨）
ので 安いので 静かなので 雨なので
のに 安いのに 静かなのに 雨なのに
し 安いし 静かだし 雨だし
ために 安いために 静かなために 雨のために

「な・な・だ・の」と縦に読んで、リズムで覚えると定着しやすいです。

② 「のに」は文句の顔で教える

先生がちょっと不満そうな顔で「昨日、宿題を出したのに……」と言ってみせます。後ろを言わなくても「何か嫌なことがあった」と伝わるのが「のに」です。

そのうえで、「のに」を使う前のチェックを一つだけ渡します。

  • 「のに」の後ろに、不満・びっくり・残念がある？ → なければ「けど」

「雨なのに、行きましょう」は、「文句を言いながら誘う人はいないよね」と笑いながら説明すると、納得してもらえます。

③ 「し」は理由のおかわり

「どうしてこの下宿にしたの？」と聞かれて、「家賃が安いし、駅に近いし、大家さんもやさしいし……」とどんどん重ねていく会話で教えます。理由を一つだけ言っても「ほかにもあるよ」という含みが出るのも、この会話なら伝わります。

ペアで、一人がアパートの広告を見て「ここに住みたい理由」を「し」で三つ続け、もう一人は「でも……なのに、高いよね」など「のに」で反論する、という活動にすると、「し」と「のに」を一度に練習できます。

④ 「ために」は「自分で決められる？」チェック

動詞カード（買う・行く・貯める・買える・上手になる・聞こえる・忘れない…）を配り、「今ここで、自分の力でできる？」で二つの箱に分けてもらいます。

  • できる（買う・行く）→ 〜ために
  • できない（買える・上手になる・聞こえる）→ 〜ように

可能形（ユニット12）が「できない箱」に入ることに気づくと、前のユニットともつながります。原因の「ために」（雨のために中止）は、「駅の放送やニュースの言葉」と紹介するだけで十分です。

練習問題

ストーリー問題：雨の日の下宿

日曜日。リンさんと蒼さんは、海へ行く約束をしていましたが……。（　）に「ので・のに・し・ために」のどれかを入れてください。形を変える必要があるものもあります。

  1. リン：「せっかくお弁当を作った（　）、雨が降ってきました……。」
  2. 蒼：「風も強い（　）、寒い（　）、今日はやめよう。」
  3. リン：「じゃあ、居間で食べませんか。千代さんも今日は一人（　）、さそいましょう。」
  4. 千代：「あら、うれしい。一人で食べるのは寂しい（　）、つい簡単なご飯になるの。」
  5. 蒼：「来週、海へ行く（　）、クーラーボックスを買おうかな。」
  6. リン：「いいですね。でも、居間で食べるお弁当もおいしい（　）、千代さんとも話せる（　）、雨の日も悪くないですね。」

ひっかけ問題：次の文には間違いがあります。直してください。

  1. リン：「来週は晴れるために、てるてる坊主を作ります。」
  2. 蒼：「雨なのに、将棋でもしようか。」
答え
  1. のに
  2. し・し
  3. なので
  4. ので（「し」も可）
  5. ために
  6. し・し
  7. 晴れるように（「晴れる」は自分で決められない）
  8. 雨だから／雨なので（「のに」の後ろに誘いは来ない）

4番のポイント：「寂しいし」だと「ほかにも理由がある」含みが出ます。どちらも正解にして、ニュアンスの違いを話し合うと盛り上がります。

この問題は、ユニット13の「冬休みの計画」の続きです。下宿の人たちは、noteのN2連載教材『月見荘の青い手紙』にも登場します。リンさんの話は、ユニット15「朝の居間の不思議」に続きます。

普通形の教え方｜「昨日買ったの本」はなぜ残る？

ユニット10は「普通形」。辞書形・ない形・た形がそろい、友達との会話、「〜と思います」「〜と言いました」、「昨日買った本」のような名詞修飾ができるようになる、N5の総仕上げです。台湾人学習者に残りやすい「の」と「だ」の教え方を紹介します。

台湾人のつまずきポイントN3

話し言葉の教え方｜って・ちゃう・とく・っけ・じゃんは「縮めた形」

ユニット29は話し言葉（って・ちゃう／とく・っけ・じゃん）。新しい文法ではなく、今まで習った形を縮めたものなので、「教科書の形⇔話し言葉」の対応表と、「だれに使っていいか」をセットで教えます。ドラマやアニメが聞き取れるようになる授業を紹介します。

台湾人のつまずきポイントN4

意向形の教え方｜「我想去」は「行きたい」？「行こうと思う」？

ユニット13は「意向形」。「〜（よ）うと思います」「〜つもりです」「〜予定です」で、これからすることを話せるようになります。中国語の「想」一つが日本語では三つに分かれる、という壁の越え方と「決心メーター」を紹介します。
