名詞文と「これ・それ・あれ」の教え方｜初日から話せる授業の作り方

2026年10月3日

この記事で分かること

ユニット1は「〜は〜です」の名詞文です。活用がないので簡単に見えますが、学習者が「日本語って楽しい」と思えるかどうかを決める、大事な最初の一歩です。

ポイントは2つです。

  1. 自分のことを話す文から入る：「〇〇の学生です」のように、初日から本当の自己紹介ができるようにする
  2. 「これ・それ・あれ」は体で覚える：中国語は「這・那」の2つなので、日本語の3つの距離感は、説明より動作で入れる

学習者がよくする間違い

間違い 正しい形 何が起きているか
×これ本は私のです この本は私のです 「これ」と「この」の区別がない
（相手の持っている物を指して）×あれは何ですか それは何ですか 「それ」と「あれ」の境目があいまい
A：それは何ですか。
B：×それはペンです		 これはペンです 答えるときに、自分の側から言い換えることを忘れる

なぜ間違えるのか

  • 中国語の指示語は2つ：中国語は「這（こちら）」と「那（あちら）」の2つです。日本語の「こ・そ・あ」の3つの距離感は、特に「そ」がつかみにくいです。
  • 「這個」は「これ」にも「この」にもなる：中国語では「這個」の後ろに名詞を置いても置かなくてもよいため、「これ＋名詞」と言ってしまいます。
  • 答えるときに視点が変わる：相手に「それ」と聞かれたら「これ」で答えます。形だけ覚えていると、聞かれた言葉をそのまま返してしまいます。

教室での教え方

① 自己紹介で「〜の〜です」

  1. 会話を何度も声に出す
    • 自己紹介の会話を「ゆっくり → もう一度ゆっくり → 少し速く → 普通のスピード → 学生だけで」と、スピードを上げながらコーラスする
    • 意味を全部説明する前に、口が勝手に動くところまで持っていく
  2. 学生が知っている名前で「〜の〜です」
    • 「学生です。学校は…〇〇大学です。〇〇大学の学生です」「会社は…△△ですね。△△の社員です」
    • 学生が知っている地元の学校名や有名企業の名前を使うと、一気に「自分のこと」になる
  3. 一人ずつ前に立って自己紹介
    • 初日から「日本語で自分のことが言えた」という成功体験を作る

② 「これ・それ・あれ・どれ」は動作で

  1. 先生が物を持って見せる
    • ペンを手に持って「これはペンです」、学生の机を指して「それは机です」、遠くの時計を指して「あれは時計です」
  2. 「どれ」は困った演技で
    • 「あれは何ですか？」と聞かれて、「んー？　これ？　これ？…どれですか？」と先生が本気で迷ってみせると、意味が一発で伝わる
  3. 学生も手を出して一緒に
    • 「みなさん、手を出してください」と、全員で「これ・それ・あれ・どれ」と指しながら言う。口と手を一緒に動かすと、距離感が体に入る
  4. 最後はペアで質問し合う
    • A「それは何ですか。」B「ああ、これは辞書です。」と、聞かれた側が「これ」で答える練習を、教室の物を使って繰り返す

練習問題

ストーリー問題：リンさんの日本語クラス初日

今日は日本語クラスの初日です。リンさんは、となりの席のマイクさんと話しています。（　）に入る言葉を書いてください。

  1. リン：「はじめまして。リンです。さくら大学（　）学生です。」
  2. リン：「マイクさんはアメリカ人ですか。」　マイク：「いいえ、アメリカ人（　）。イギリス人です。」
  3. （マイクさんが持っている本を指して）リン：「（　）は何ですか。」
  4. マイク：「ああ、（　）は日本語の辞書です。」
  5. （教室のいちばん後ろのポスターを指して）マイク：「（　）は何ですか。」　リン：「日本の地図です。」
  6. （机の上のノートを手に取って）リン：「（　）ノートは誰のですか。」
答え
  1. の
  2. じゃないです（ではありません）
  3. それ
  4. これ
  5. あれ
  6. この
