## この記事で分かること

推量・伝聞は、意味ではなく**「その情報をどこから手に入れたか」**で分けると整理できます。

| 形 | 情報の出どころ | 例 |
| --- | --- | --- |
| 〜そうだ（様態） | 目で見た様子。まだ確かめていない | このケーキ、おいしそう。 |
| 〜ようだ | 自分の観察や体験をもとに、頭で判断 | だれかがこの部屋に入ったようだ。 |
| 〜らしい | 人から聞いた話など、耳から入った情報。少し距離がある | 山田さんは来月、結婚するらしい。 |
| 〜そうだ（伝聞） | 聞いた話をそのまま伝える | 天気予報によると、明日は雨だそうだ。 |

この文法は、推理小説の探偵が一番よく使う言葉でもあります。「犯人はこの窓から入ったようだ」「事件の夜、雨が降っていたそうだ」。教室では学習者に探偵になってもらうと、楽しく使い分けが身につきます。

## 学習者がよくする間違い

| 間違い | 正しい形 | ポイント |
| --- | --- | --- |
| ×（ケーキを見て）おいしいそうです。 | おいしそうです。 | 「おいしいそう」は「おいしいと聞いた」の意味になる |
| ×（空を見て）雨が降るそうです。 | 雨が降りそうです。 | 目で見た様子は「ます形＋そう」 |
| ×このかばんはいいそうです。 | このかばんはよさそうです。 | 「いい」「ない」は「よさそう」「なさそう」 |
| ×彼女はきれいそうです。 | 彼女はきれいです。／きれいな人らしいです。 | 見ただけで分かることに「そう」は使わない |
| ×（自分で食べて）この料理は辛いようです。 | この料理は辛いです。 | 自分で確かめたことは断定でいい |
| ×天気予報によると、明日は雨が降りそうです。 | ……明日は雨が降るそうです。 | 「によると」があれば伝聞。普通形＋そうだ |
| ×明日は雨そうです。（伝聞） | 明日は雨だそうです。 | 名詞の伝聞は「だそうだ」 |
| △新しい先生は男らしいです。（「男の人だと聞いた」のつもり） | 新しい先生は男の人らしいです。 | 「男らしい」は「いかにも男性的な性格・態度」という別の意味になる |

## なぜ間違えるのか

### ① 中国語は「好像」でほぼ済む

「好像要下雨了」「他好像是學生」「好像很好吃」――目で見た様子も、頭での判断も、うわさも、全部「好像」で言えます。そのため「そうだ・ようだ・らしい」を「全部好像」と覚えてしまい、違いを意識するきっかけがありません。

### ② 二つの「そうだ」は接続しか違わない

「降りそうだ（看起來要下雨）」と「降るそうだ（聽說要下雨）」。語尾の違いは一、二文字ですが、意味はまったく別物です。形の小さな違いに大きな意味の違いが乗っているので、注意していても間違えます。

### ③ 「ようだ」と「らしい」の境目があいまい

どちらも「たぶんそうだ」という判断で、日本人も入れ替えて使う場面があります。教科書の説明（「らしいは客観的」など）だけでは、学習者は実際にどちらを選べばいいか分かりません。

### ④ 「はっきり言わない」習慣が強すぎる

教室で「断定しすぎないように」と教わった学習者ほど、自分で食べた料理にも「辛いようです」と使ってしまいます。推量は「まだ確かめていないこと」に使うもの、という前提が抜けているのです。

## 教室での教え方

### ① 「目・頭・耳」の三つの絵を黒板に貼る

黒板に目・頭・耳の絵を並べて貼り、それぞれの下に形を書きます。

- 目 → 〜そうだ（おいしそう・降りそう）
- 頭 → 〜ようだ／〜みたい
- 耳 → 〜らしい、〜そうだ（伝聞）

例文を出すたびに「これはどこから入ってきた情報？」と聞き、学習者に絵を指さしてもらいます。形の説明より先に「出どころ」を意識する習慣がつきます。

### ② 二つの「そうだ」は「聽說テスト」で見分ける

文の頭に「聽說」をつけて意味が通れば伝聞、「看起來」をつけて通れば様態。中国語を逆に利用する方法です。そのうえで、接続を一枚の表にまとめます。

|  | 様態（看起來） | 伝聞（聽說） |
| --- | --- | --- |
| 動詞 | 降りそうだ | 降るそうだ |
| い形容詞 | 高そうだ | 高いそうだ |
| な形容詞 | 便利そうだ | 便利だそうだ |
| 名詞 | （使わない） | 雨だそうだ |

「伝聞は形を崩さずにそのままつける。聞いた言葉をそのまま運ぶから」と説明すると、覚えやすくなります。

### ③ 探偵ゲームで「ようだ」を使う

事件現場の絵（割れたコップ、開いた窓、泥の足あとなど）を配り、グループで推理して発表します。

- 「足あとが大きい。犯人は背の高い人のようだ。」
- 「コップがまだ温かい。さっきまでだれかいたようだ。」

そのあと「証人カード」（「隣の人の話：夜中に大きな音がした」）を配ると、「夜中に大きな音がしたそうだ／らしい」と、耳からの情報の練習にもつながります。推理小説の教材と組み合わせやすい活動です。

### ④ 「確かめたら断定」を一言添える

「そう・よう・らしいは、まだ確かめていないときの言葉。自分で食べたら『辛い』でいい」。この一言を最後に伝えるだけで、使いすぎの間違いが減ります。

## 練習問題

**ストーリー問題：消えたプリン**

下宿の冷蔵庫から、リンさんのプリンが消えました。リンさんと蒼さんが推理します。（　）の中から正しい方を選んでください。

1. リン：「あれ？　私のプリンがない……。だれかが食べた（ようです／そうです）。」（空のカップがごみ箱にある）
2. 蒼：「このスプーン、まだぬれている。犯人は、さっきまでここにいた（みたいだ／そうだ）な。」
3. リン：「千代さんに聞いたら、早瀬さんが夜中に台所にいた（らしいです／いそうです）。」
4. 蒼：「でも早瀬さんは、甘い物が大嫌い（だそうだ／そうだ）よ。」
5. リン：「あ、あそこに新しいプリンがあります。とても（おいしそう／おいしいそう）……。」
6. 蒼：「メモが貼ってある。『リンさんへ。間違えて食べてしまったので、新しいのを買ってきました。千代』……犯人はばあちゃん（だったようだ／だった）！」

**ひっかけ問題：次の文の間違いを直してください。**

7. リン：（新しいプリンを一口食べて）「このプリン、前のよりおいしいようです！」
8. 蒼：「天気予報によると、明日は晴れそうだよ。」

<details>
<summary>答え</summary>

1. ようです
2. みたいだ
3. らしいです
4. だそうだ（な形容詞の伝聞）
5. おいしそう
6. だった（メモで確かめたので断定）
7. おいしいです（自分で食べた）
8. 晴れるそうだ（「によると」は伝聞）

</details>

> **3番**の選択肢「いそうです」は様態で、ここでは意味が通りません。**6番**は、証拠がそろったら推量をやめて断定する、という探偵らしい終わり方にしてあります。
