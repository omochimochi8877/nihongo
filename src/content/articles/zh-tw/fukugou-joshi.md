## 這個單元學什麼

複合助詞比起會話，更常出現在**報紙和說明文裡，是「閱讀的文法」**。很多和中文的介詞（關於・對於・由・作為）很像，所以意思不難懂。但是對應「不是一對一」，容易在這裡卡住。

四個各畫成一張圖，就很好整理：

| 形 | 畫成圖 | 中文的感覺 | 例子 |
| --- | --- | --- | --- |
| 〜について | 話題的「箱子」 | 關於 | 日本の文化について発表する。 |
| 〜に対して | 朝向對方的「箭頭」／左右的「天秤」 | 對、對於／而 | 先生に対して失礼だ。／兄が背が高いのに対して、弟は低い。 |
| 〜によって | 分開的「岔路」／誰做的 | 因…而異／由 | 人によって考え方が違う。／この寺は弟子たちによって建てられた。 |
| 〜として | 那個身分的「名牌」 | 作為 | 留学生として日本に来た。 |

## 常見錯誤

| 錯誤 | 正確 | 重點 |
| --- | --- | --- |
| ×日本の文化に対して、レポートを書きました。 | ……文化について、…… | 談話或報告的主題用「について」 |
| ×彼は先生について、失礼な態度をとった。 | ……先生に対して、…… | 對某人的態度・行為用「に対して」 |
| ×国について、習慣が違います。 | 国によって、習慣が違います。 | 「因…而異」是「によって」 |
| ×この寺は、有名な僧によって建てました。 | ……建てられました。 | 「によって」表示做的人時，和被動一起用 |
| ×私として、日本語の漢字は簡単です。 | 私にとって、…… | 「對我來說」是「にとって」，「として」是身分・資格 |
| ×日本の歴史についてな本を読んだ。 | ……歴史についての本を…… | 名詞前面是「についての」 |
| △お客さんに対しての言葉づかい。 | お客さんに対する言葉づかい。 | 「に対しての」也有人用，但基本是「に対する」 |
| ×地震によっての被害が大きい。 | 地震による被害が…… | 名詞前面是「による」 |

## 為什麼會錯？

- **「對於」可以是「について」也可以是「に対して」**：「對於這個問題，我有意見」是「この問題について」，「對老師沒禮貌」是「先生に対して」。如果用字形記成「對＝に対して」，說主題時也會用「に対して」。
- **「によって」有三、四個意思**：「人によって違う（因…而異）」「弟子によって建てられた（由）」「話し合いによって決める（透過）」「台風によって電車が止まった（因為）」。中文都是不同的詞。
- **「作為」和「對…來說」搞混**：「作為留學生」＝「留学生として」，「對我來說」＝「私にとって」。都在說自己的立場，形狀又很像，所以容易搞錯。
- **名詞前面形狀會變**：について→についての、に対して→に対する、によって→による、として→としての。中文只要加「的」，所以更容易亂。

## 記憶小技巧

- **四張圖卡**：
  - について → 裝著話題內容的「箱子」
  - に対して → 朝向人的「箭頭」
  - によって → 分成好幾條的「岔路」
  - として → 別在胸前的「名牌」
  - 不要想中文翻譯，看圖選：「說的是內容，就是箱子」。
- **「によって」從「〜によって違う」開始**：「国によって」「人によって」「季節によって」——台灣和日本的不同，可以說很多。
- **名詞前面的形狀**：

| 句子中 | 名詞前面 |
| --- | --- |
| について | についての（本） |
| に対して | に対する（態度） |
| によって | による（被害） |
| として | としての（責任） |

  「に対して→に対する」「によって→による」是變回辭書形的一組，「について→についての」「として→としての」是加「の」的一組。
- **用新聞標題練習閱讀**：「台風による被害」「少子化に対する対策」「観光客としてのマナー」——猜猜看是什麼新聞？

## 練習題

**故事題：リン的報告稿**

リン要在大學的課上報告「日本和台灣的不同」。她在宿舍寫稿子。請在（　）裡填入「について・に対して・によって・として」其中一個的正確形。

> 1. 今日は、日本と台湾の食文化（　）お話しします。
> 2. 私は留学生（　）、一年前に日本へ来ました。
> 3. 朝ご飯の習慣は、国（　）大きく違います。
> 4. 日本では家で朝ご飯を作る人が多い（　）、台湾では外で買う人が多いです。
> 5. 下宿の大家さんは、私たち留学生（　）、いつも優しくしてくれます。
> 6. この下宿は、大家さんのお父さん（　）六十年前に建てられました。

**陷阱題：下面的句子有錯，請改正。**

7. 私として、納豆はまだ少し難しい食べ物です。
8. 最後に、台湾の夜市についてな動画をお見せします。

<summary>答案</summary>

1. について
2. として
3. によって
4. のに対して（日本和台灣放在天秤兩邊比較）
5. に対して
6. によって
7. 私にとって（「對我來說」）
8. 夜市についての動画（名詞前面）
