## 這個單元學什麼

[第19單元](/nihongo/zh-tw/articles/souda-youda-rashii/)用「眼睛・頭腦・耳朵」來分推測和傳聞。N3再加上「はずだ」，進一步用**「根據是什麼、有多確定」**來分。

| 形 | 根據 | 例子 |
| --- | --- | --- |
| 〜はずだ | 從事實或道理來想，「當然會這樣」 | メールを送ったから、もう読んだはずだ。 |
| 〜ようだ | 自己看到、感覺到的 | 電気がついている。だれかいるようだ。 |
| 〜みたいだ | 「ようだ」的口語版 | だれかいるみたい。 |
| 〜らしい | 從別人那裡聽來的・傳聞 | あの店、来月閉店するらしい。 |

N3還會出現推測以外的用法：「まるで夏のようだ」（比喻）、「春らしい天気」（很有春天的感覺）、「来るはずだったのに」（預料落空）。

## 常見錯誤

| 錯誤 | 正確 | 重點 |
| --- | --- | --- |
| ×私は来年、日本へ留学するはずです。（自己決定的） | ……留学するつもりです／予定です。 | 自己的意志不用「はず」 |
| ×学生なら、もっと勉強するはずだ。（「應該要」的意思） | ……もっと勉強するべきだ。 | 「應該（要做）」是「べきだ」（第24單元） |
| ×（看著窗外）外は寒いはずです。 | 外は寒いようです。 | 眼前的樣子用「ようだ」，「はず」是從道理推 |
| ×あの人は先生のみたいです。 | あの人は先生みたいです。／先生のようです。 | 名詞＋みたい、名詞＋の＋よう |
| ×この部屋は静かのはずです。 | この部屋は静かなはずです。 | な形容詞＋な＋はず |
| ×まるで夢みたいの話です。 | まるで夢みたいな話です。／夢のような話 | 名詞前面是「みたいな」「のような」 |
| △（四月）今日はとても春みたいな天気です。 | 今日はとても春らしい天気です。 | 「春みたい」是不是春天時的比喻。春天很有春天的感覺用「らしい」 |

## 為什麼會錯？

- **「應該」同時有「はず」和「べき」**：「他應該到了」（もう着いたはず）和「你應該去」（行くべき）。中文都是「應該」，日文分成「推測」和「義務」。記成「はず＝應該」，就會說出「勉強するはずだ」。
- **「應該」也能說自己的計畫**：「我明年應該會去日本」是有點不確定的計畫，很自然。直接說「行くはずです」，日文聽起來像「別人決定的行程」。自己的意志用[第13單元](/nihongo/zh-tw/articles/ikoukei/)的「つもり・予定」。
- **「ようだ」和「みたいだ」接續不同**：意思差不多，名詞後面卻是「先生のよう」和「先生みたい」。
- **一個形狀有兩個意思**：「ようだ」是推測（好像）和比喻（像…一樣），「らしい」是傳聞（聽說）和很有…的樣子。中文是不同的詞，所以不容易發現。

## 記憶小技巧

- **「はずだ」和「だから」一起用**：「六時の新幹線に乗った。だから、もう東京に着いたはずだ」。說不出根據的話，就不能用「はず」。
- **「應該」的三種翻法**：自己的打算＝つもり，該做的事＝べき，有根據的推測＝はず。
- **接續表**：

|  | ようだ | みたいだ |
| --- | --- | --- |
| 動詞 | 降るようだ | 降るみたいだ |
| な形容詞 | 静かなようだ | 静かみたいだ |
| 名詞 | 先生のようだ | 先生みたいだ |
| 名詞前面 | 〜のような＋名詞 | 〜みたいな＋名詞 |

- **比喻用台灣的例子**：「台湾の夏は、まるでサウナのようだ」「夜市の人の多さは、まるでお祭りみたいだ」。

## 練習題

**故事題：沒回家的蒼**

晚上九點。蒼還沒回到宿舍。リン和千代很擔心。請在（　）裡填入「はず・よう・みたい・らしい」其中一個的正確形。

1. 千代：「おかしいわ。蒼は今日、八時には帰る（　）だったのに。」
2. リン：「メッセージを送りましたが、既読になっていません。携帯を見ていない（　）です。」
3. 千代：「そういえば、今朝『今日はサークルの飲み会があるかも』と言っていたわ。」　リン：「じゃあ、飲み会に行った（　）ですね。」
4. （開門的聲音）蒼：「ただいまぁ……」　リン：「蒼さん、顔が真っ赤。まるでゆでダコ（　）ですよ！」
5. 蒼：「先輩が来月、台湾に留学する（　）んだ。まだ秘密だけど、そういううわさ。」
6. 千代：「あら、それで送別会だったのね。蒼は一番若いから、たくさん飲まされた（　）だわ。」

**陷阱題：下面的句子有錯，請改正。**

7. 蒼：「これからは、飲み会の日は先に連絡するはずです。」（自己決定的事）
8. リン：「そうしてください。千代さんは、本当のおばあさんのようの心配していましたよ。」
