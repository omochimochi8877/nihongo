学習の流れN5〜N3・全30ユニット

このシラバスの考え方

活用の形を1つ覚えたら、その形で作れる文型をまとめて覚えます。たとえば「て形」を覚えたら、「てください・ています・てもいい」を一気に学びます。新しく覚える形は1回で済み、使える文がすぐに増えるので、頭に残りやすくなります。

  • N5・N4：新しい「活用の形」ごとに区切る
  • N3：新しい活用がほとんどないので、「意味のグループ」ごとに区切る
  • いちばん時間をかけるのは「て形」と「条件（と・たら・ば・なら）」

※N5〜N3の分け方は、市販の対策書でよく使われる目安です（日本語能力試験は2010年以降、公式の文法リストを出していません）。

N5N4N3

N5活用を一つずつ覚えるユニット1〜10

  1. ます形

    1

    名詞文：〜は〜です／じゃないです／ですか、の（所属）、こ・そ・あ・ど

    • 📝 名詞文と「これ・それ・あれ」の教え方｜初日から話せる授業の作り方
    2

    存在文：あります／います、位置（上・中・隣）、〜に〜があります

    • 📝 「あります」と「います」の教え方｜中国語の「有」から抜け出すコツ
    3

    ます形：〜ます／ません／ました、を・へ・で・と・に（時間）

    • 📝 「ます・ません・ました」の教え方｜「昨日、映画を見ません」はなぜ起きる？
    4

    形容詞：い形容詞・な形容詞（今と過去）、〜が好き／上手

    • 📝 形容詞の教え方｜「大きいの家」「おいしいでした」はなぜ起きる？

  2. ます形の応用

    5

    〜ませんか／ましょう、〜たいです、〜に行きます（目的）

    • 📝 「ませんか・ましょう」の教え方｜「映画を見たいですか？」で誘うと変？

  3. て形★ いちばん時間をかける

    6

    てください、ています（している最中）、てもいいですか、てはいけません、〜て、〜てから

    • 📝 て形の教え方｜学習者を挫折させない5つのコツ

  4. ない形

    7

    ないでください、なければなりません、なくてもいいです

    • 📝 ない形の教え方｜「不用」と「不可以」を混ぜないために

  5. 辞書形・た形

    8

    辞書形：〜ことができます、趣味は〜ことです、〜前に

    • 📝 辞書形の教え方｜「日本語を話すができます」はなぜ起きる？
    9

    た形：〜たことがあります、〜たり〜たり、〜た後で

    • 📝 た形の教え方｜「昨日、寿司を食べたことがあります」はなぜ変？

  6. 普通形

    10

    普通体の会話、〜と思います、〜と言いました、名詞修飾（昨日買った本）

    • 📝 普通形の教え方｜「昨日買ったの本」はなぜ残る？

N4新しい活用＋似ている文法の比較ユニット11〜20

  1. 名詞修飾の応用

    11

    〜時、〜のは／〜のが、〜んです

    • 📝 「時・のは・んです」の教え方｜「日本へ行く時」と「行った時」はどう違う？

  2. 可能形・意向形

    12

    可能形：食べられる・話せる、〜ようになる、〜ように（目的）

    • 📝 可能形の教え方｜「會・能・可以」が全部ひとつに？「話せれる」を防ぐコツ
    13

    意向形：〜（よ）うと思います、〜つもりです、〜予定です

    • 📝 意向形の教え方｜「我想去」は「行きたい」？「行こうと思う」？

  3. 理由・逆接

    14

    〜ので、〜のに、〜し、〜ために

    • 📝 「ので・のに・し・ために」の教え方｜「因為」も「可是」も一つじゃない

  4. 自動詞・他動詞

    15

    開く／開けるなどのペア、ている（結果の状態）、てある、ておく

    • 📝 自動詞・他動詞の教え方｜「手」が見えるかで分ける、ている・てある・ておく
    16

    てしまう、てみる、ていく／てくる

    • 📝 「持ってくる」と「持っていく」の教え方｜学習者が混乱する2つの理由

  5. 授受

    17

    あげる・もらう・くれる → てあげる・てもらう・てくれる

    • 📝 あげる・くれる・もらうの教え方｜「給」は三つに分かれる

  6. 条件★ いちばん時間をかける

    18

    と → たら → ば → なら を一つずつ。最後に「使い分け」の回

    • 📝 と・ば・たら・ならの教え方｜「たら」を基本にして三つを足す

  7. 推量・伝聞

    19

    〜そうです（見た感じ）、〜でしょう／かもしれません、〜そうです（聞いた話）

    • 📝 そうだ・ようだ・らしいの教え方｜「好像」を「情報の出どころ」で分ける

  8. 受身・使役・敬語

    20

    受身 → 使役 → 使役受身、尊敬語・謙譲語、ていただく（まずは「聞いて分かる」が目標）

    • 📝 受身・使役・敬語の教え方｜「だれが主語？」でまとめて教える

N3意味のグループで覚えるユニット21〜30

各ユニットの最後は「似ている文法の比較表」でまとめます。

  1. 推量の使い分け

    21

    〜ようだ、〜みたいだ、〜らしい、〜はずだ

    • 📝 ようだ・みたいだ・らしい・はずだの教え方｜「應該」＝「はず」じゃない？

  2. 時間の局面

    22

    〜ところだ、〜たばかり、〜うちに、〜間に、〜最中に、〜とたん

    • 📝 ところだ・たばかり・うちに・とたんの教え方｜「いつ？」を一本の線で整理

  3. 決定・判断

    23

    〜ことにする／ことになる、〜ようにする／ようになる（復習）

    • 📝 ことにする・ことになる・ようにする・ようになるの教え方｜二つのスイッチで整理
    24

    〜わけだ／わけがない、〜べきだ、〜に違いない

    • 📝 わけだ・べきだ・に違いないの教え方｜「難怪」「應該」「一定」は文末で言う

  4. 逆接・程度

    25

    〜ても、〜のに（復習）、〜くせに、〜としても

    • 📝 ても・のに・くせに・としてもの教え方｜逆接は「感情の温度」で分ける
    26

    〜ば〜ほど、〜ほど／くらい、〜さえ、〜ばかり

    • 📝 ば〜ほど・ほど・さえ・ばかりの教え方｜「越…越」「連…都」「只要」と対応させる

  5. 複合助詞

    27

    〜について、〜によって、〜に対して、〜として

  6. 使役・敬語の応用

    28

    〜させてください、〜させていただく、〜てもらえませんか（N4で「分かる」だったものを「使える」に）

  7. 話し言葉・総復習

    29

    〜って、〜ちゃう／とく、〜っけ、〜じゃん

    30

    N5〜N3の「似ている文法」の比較表をまとめて練習（N2教材への橋渡し）

📝 が付いているユニットは、教え方の記事があります。記事は少しずつ増やしていきます。
